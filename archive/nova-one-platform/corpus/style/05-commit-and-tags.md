# المعيار 05 — الالتزامات والوسوم (v0.1.0)

## الالتزامات

Conventional Commits: `feat:`، `fix:`، `docs:`، `test:`، `refactor:`، `chore:` — سطر عنوان ≤72 حرفاً + جسد عربي يشرح «لماذا» لا «ماذا».

## الوسوم

- كل بوابة مغلقة = وسم إصدار `vMAJOR.MINOR.PATCH` يُرفع فوراً.
- MINOR لكل مخرج مرحلة قابل للاختبار؛ PATCH لإصلاح ضمن نفس المخرج؛ MAJOR عند كسر عقد.
- وسم بلا أدلة خضراء في CI = وسم باطل يُحذف.

## سجل التغييرات

`CHANGELOG.md` يُحدَّث مع كل وسم — مدخل لكل إصدار: أُضيف/تغيّر/أُصلح + أدلة.
