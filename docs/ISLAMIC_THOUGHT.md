# العقل الفكري — طبقة كتب الفكر الإسلامي في نواة المعرفة

> أُضيفت في **v1.7.0** · المصدر: قائمة مُنَسَّقة من بحث «خريطة الفكر الإسلامي»
> (12 مدرسة، ~470 مفكراً، ~1,580 كتاباً أصلياً، ~300 فكرة مميزة بدون تكرار)

## 1) ما هذه الطبقة؟

الفرق الجوهري الذي يقوم عليه التصميم:

- **الفلسفة الإسلامية** تسأل: *ما الحقيقة؟* (الوجود، المعرفة، النفس).
- **الفكر الإسلامي** يسأل: *ما العمل؟* (لماذا تخلف المسلمون؟ كيف نبني دولة؟
  ما العدالة الاجتماعية؟ ما علاقة الدين بالدولة؟ ما النهضة؟)

طبقة «العقل الفكري» تُدخل السؤال الثاني إلى نواة المعرفة على ثلاث مستويات
مرقّمة بحقول مستقلة:

| المستوى | الجدول | الحجم الحالي | المصدر |
|---|---|---|---|
| **المدارس** | `data/knowledge/fikr_manifest.json` → schools | 12 مدرسة | بحث المكتبة |
| **الكتب** | `books` + `authors` (source_id=fikr) | 12 كتاباً مُجمَّعاً / 28 في القائمة | مرآة الشاملة |
| **المقاطع** | `passages` (بإثبات صفحي) | **54,353 مقطعاً** / 26.9M حرف | مرآة الشاملة |
| **الأفكار** | `claims` | **32 فكرة محورية** بإسناد صاحبها ومدرستها | بحث المكتبة |

## 3) الكتب المعلَّقة (محفوظة الحقوق أو خارج المرآة) — القائمة كاملة في
`fikr_manifest.json` مع مصدر جمع مقترح لكل كتاب

الموافقات (الشاطبي)، مقدمة ابن خلدون، العروة الوثقى، الخلافة أو الإمامة
العظمى، تحرير المرأة (قاسم أمين)، المصطلحات الأربعة (المودودي)، معالم في
الطريق والعدالة الاجتماعية (سيد قطب)، اقتصادنا وفلسفتنا (الصدر — eshia)،
الحكومة الإسلامية (الخميني)، الإسلام وأصول الحكم (عبد الرازق)، نقد العقل
العربي (الجابري)، التراث والتجديد (حنفي)، الوسطية وفقه الأولويات (القرضاوي).

## 4) كيف تستعملها؟

```bash
# البحث في المقاطع (بإثبات صفحة)
python -m ryko_lm.knowledge search --db data/knowledge/ryko.sqlite "الاستبداد أصل كل فساد" -k 5

# البحث في طبقة الأفكار (claims بإسناد المدرسة وصاحبها)
python -m ryko_lm.knowledge ideas --db data/knowledge/ryko.sqlite "الحاكمية" -k 5

# زرع الأفكار من المانيفست (إلحاقيّ لا يُكرر)
python -m ryko_lm.knowledge ideas-seed --db data/knowledge/ryko.sqlite

# جمع كتب جديدة عند توفرها في المرآة: أضفها إلى fikr_manifest.json بحالة
# available + shamela_path ثم:
python -m ryko_lm.data.collect_fikr --out data/raw/fikr_shamela.jsonl
python -m ryko_lm.knowledge ingest --db data/knowledge/ryko.sqlite \
    --jsonl data/raw/fikr_shamela.jsonl --format fikr
```

**عبر الـAPI:**

```bash
GET /knowledge/ideas?q=لماذا تخلف المسلمون&k=5
GET /knowledge/search?q=شروط النهضة إنسان تراب وقت&k=5
```

## 5) الضمانات المنهجية

1. **إسناد صفحي لكل مقطع**: `book_id + page_num + seq + text_sha256` — نفس
   عقد `ryko-cite/1`، فأي فكرة يمكن تدقيق نصها الأصلي.
2. **حتمية كاملة**: معرّفات `stable_id`، ترتيب بحث ثابت `(-score, claim_id)`.
3. **بصمة مصدر مستقلة**: source_id=`fikr` مع `rights_status=declared-open`
   (نفس ترخيص المرآة المعلن، مع تحفظ حقوق تحقيق الطبعات).
4. **حصرية القائمة**: الأفكار الزرعية آتية نصاً من بحث المكتبة لا من توليد
   النموذج — `confidence=1.0` تعني «إسناد موثق من المصدر البشري».
5. **التنظيف عند الجمع**: وسم العناوين في المرآة (`<span data-type=…>`)
   يُقشَّر في `collect_fikr.strip_markup` قبل الاستيراد.

## 6) الحدود الصريحة

- بذرة v1.3.0 العشرة كتب (11,674 مقطعاً) جمعت قبل نظام القشط — بقايا وسم
  فيها ~1.7%؛ تعاد بناؤها بأول إعادة جمع للمدونة.
- 16 كتاباً من أهم كتب الفكر **المعاصر** محفوظة الحقوق وغير قابلة للجمع
  الآلي — القائمة توثق مصدرها للمرجعية البشرية.
- طبقة `argument_relations` (علاقات النصرة/النقض بين الأفكار — مثلاً رد
  الغزالي على قطب، ورد قطب على مالك بن نبي) تُزرع يدوياً في إصدار قادم؛
  الجدول جاهز في المخطط.
