# تقرير فحص المستودع — W0

**التاريخ:** 2026-11-12 | **المُعد:** وكيل البرمجة | **الحالة:** ⚠ مسودة — تُستكمل وتُوقّع قبل W1

## البروتوكول المنفذ

```bash
git log --oneline -20 && git status          # حالة الفرع والنظافة
tree -L 3 -I 'node_modules|.git'             # البنية الفعلية
cloc . && pip-audit && flutter pub outdated  # الحجم والاعتماديات
gitleaks detect                              # أسرار مسربة
pytest --collect-only -q                     # جرد الاختبارات الموجودة
```

## قائمة النتائج

- [ ] حالة الفرع: `main` نظيفة، لا توجد ملفات غير متتبعة.
- [ ] الأمان: لا توجد أسرار مسربة (gitleaks = 0)، لا توجد ثغرات حرجة في الاعتماديات.
- [ ] الاختبارات: مجموعة ذهبية (500 حالة) قابلة لإعادة الإنتاج بايت-ببايت (بذرة ثابتة 42).
- [ ] البوابات: `make safety-gates` (حساسية ≥99%، نوعية ≥85%، 0 طمأنة لألم الصدر) ناجحة.
- [ ] التكافؤ: `make parity` — الحمولة الموحدة Python↔Dart مطابقة بايت-ببايت.
- [ ] وحدة PHARMA: [تبنّي / إعادة هيكلة / حجر] - (يُحدد بناءً على وجود اختبارات وعقود؛ مرشح المرحلة: `pharma-sdl`).
- [ ] قرار W1: تم اعتماد البدء بكتابة قواعد السلامة.

## ملاحظات فحص وحدة pharma-sdl

الوحدة المرشحة `pharma-sdl` (على github.com/tibatechapp-ship-it) تُفحص بنفس البروتوكول أعلاه؛ ما ينجح منه يُرحّل كـ adapter على العقود (`contracts/v1/interaction_check.schema.json`)، والباقي يُعاد بناؤه. العلم التنظيمي `pharma.interactions` يبقى **مطفأً** حتى توقيع ترخيص KB.
