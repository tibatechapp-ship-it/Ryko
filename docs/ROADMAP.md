## 0) الموقع الحالي في سطر واحد

Ryko اليوم **أنبوب كامل قابل لإعادة الإنتاج** (كوربوس ← رمزنة ← تدريب ← تقييم
← خدمة ← إيصالات provenance) بمدونة تراثية **v5.2 = 747.9 مليون توكن** (v5.1
أعيد بناؤها بتحقق مرحلي حرفي ثم أُضيفت شاملة الاختيار الواسع بمزج احتجاز
**مجمّد بايت-ببايت** — sha256 `ef10b145…` محفوظ) ونموذج Ryko-Tiny (11.5M
معلم) استُأنف إحماؤه بشظية v5c: ارتباكه على التحقق الكلاسيكي الأشد
**225.1 ← 221.4**، و**MCQ في RYKO-Bench 25.9% ← 26.5%** واقتباس 100% محفوظ
على بذرة 259 حالة، و**أول تحقق خارجي** (PalmX-IC، 981 حالة) منشور بأمانة.

**ما أُضيف هذا الإصدار كأدوات (وليس بيانات فقط):**

- `ryko_lm.data.collect_openiti` — بثّ شظايا parquet + تنظيف mARkdown، قابل للاستئناف.
- `ryko_lm.data.collect_shamela` — اختيار طبقي لكتب مشهورة + تنزيل متوازٍ + سجل تقدم.
- `ryko_lm.data.augment_corpus` — توسيع تدريجي بذاكرة ثابتة: بصمات FNV/int للفقرات،
  إزالة تكرار عالمية، دمج old+new دون إعادة تنظيف الكل.
- `ryko_lm.eval.evaluate` — بروتوكول تقييم **حتمي** (نوافذ متتالية غير متداخلة، بلا RNG)
  + توليد موحد البذور + خيار كبح EOS لعينات الطلاقة.
- `ryko_lm.provenance` — **إيصالات sha256 قابلة للتحقق دون اتصال** (نمط ZYKO):
  `python -m ryko_lm.provenance make|verify`.
- `ryko_lm.serving.guard` — **حارس ما قبل التسليم**: نسبة عربية، حلقات تكرار،
  بقايا markup، قرار ALLOW/REVIEW مختوم بهاش (نمط ZYKO guardian).
- `ryko_lm.training.export` — تصدير last.pt ← final.pt بصيغة الخدمة (fp16 + تكوين).

### المرحلة 5 — ryko-small على GPU (بعد 3+4)

### المرحلة 6 — RYKO Knowledge Core (قاعدة المعرفة)
- **العمل:** تحويل إثبات المصدر الموجود فعلاً (book_id/page_num في بيانات

  `passages`, `claims`, `argument_relations` (المخطط في بحث RYKO المرفق)، مع

- **بوابة القبول:** كل مقطع يمكن إرجاعه إلى كتاب + صفحة + بصمة sha256؛
  إيصال provenance لكل دفعة استيراد.
- **الحالة:** ✅ **v1.3.0 سلّم الأساس المحلي** — مخطط SQLite للجداول الستة
  (`ryko_lm.knowledge`)، استرجاع هجين حتمي (BM25 + hashing-embeddings + RRF)،
  مدقق اقتباس، بذرة 10 كتب / 11,674 مقطعاً بإسناد صفحي وإيصال متحقق.  الباقي:
  خادم PostgreSQL + pgvector عند التوسع، وتضمينات دلالية عربية حقيقية.
- **هذا هو الأساس للـ RAG الموثق قبل أي ضبط دقيق.**
- **الطبقات المنقوحة فوق الأساس:** طبقة الفكر المنقح v1.7.0/v1.8.0
  (`docs/ISLAMIC_THOUGHT.md`) وطبقة الاقتصاد والحقوق v1.9.0

  آلياً + كتب مُنسَّقة بإثبات صفحة + أفكار بإسناد، وعزل طبقات مختبر.
  وفوقها رسم علاقات الحجاج v1.10.0: 35 علاقة موثقة بين الأفكار
  (`argument_relations` + `GET /knowledge/relations`).
- **طبقة التراث الشامل المُنتقى v1.16.0** (`docs/KNOWLEDGE_CORE.md` §10):
  نفس الاختيار الواسع المدمج في v5.2 مستورد بإسناد صفحي — 358 كتاباً مجمّعة،

## 3) القرارات الهندسية الثابتة

1. **لا نغيّر الرمّاز** (32K Byte-Level BPE) إلا بتجربة MorphBPE/CAMeL موثقة
   تُظهر مكسباً في المهام — تغيير المفردات يعني إعادة تدريب كاملة.
2. **الاستئناف بالضبط** شرط للبنية: كل جلسة تدريب يجب أن تُغلق بحفظ `last.pt`.
3. **كل رقم يُقاس ببروتوكول حتمي واحد** (`ryko_lm.eval.evaluate`، نوافذ متتالية
   كاملة) — أي رقم بروتوكول آخر لا يُقارن.
4. **كل أصل (corpus/checkpoint) يحمل إيصالاً** موقّعاً قبل الإعلان عنه.
5. **الأمانة العلمية أولاً:** النموذج لا يُقدَّم كمرجع شرعي؛ التقييم يفصل
   الامتناع عن الهلوسة، والبوابات تُقبل/تُرفض بالأرقام لا بالانطباع.

## 4) أوامر نواة المعرفة (المرحلة 6 — v1.3.0)

```bash
python -m ryko_lm.data.collect_shamela --per-cat 1 --max-books 12 --max-file-mb 3 \
    --keep-pages --out data/raw/shamela_knowledge.jsonl          # جلب بإسناد صفحي
python -m ryko_lm.knowledge ingest --format shamela \
    --jsonl data/raw/shamela_knowledge.jsonl --db data/knowledge/ryko.sqlite
python -m ryko_lm.knowledge search --db data/knowledge/ryko.sqlite "استعلامك" -k 5
python -m ryko_lm.knowledge cite   --db data/knowledge/ryko.sqlite "نص الاقتباس"
python -m ryko_lm.knowledge ideas  --db data/knowledge/ryko.sqlite "استعلامك" --layer econom
python -m ryko_lm.knowledge relations --db data/knowledge/ryko.sqlite --layer fikr
python -m ryko_lm.security.secret_scan --tree .                   # بوابة الأسرار
```

أو عبر Makefile: `make knowledge-ingest` · `make knowledge-search Q="..."`
· `make knowledge-cite Q="..."` · `make knowledge-receipt` · `make secret-scan`.
التفصيل الكامل في `docs/KNOWLEDGE_CORE.md`.
