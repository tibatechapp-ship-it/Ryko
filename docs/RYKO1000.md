# RYKO-1000 — مجموعة البيانات الإنتاجية (10 عائلات × 100 حالة)

الحالة: **مُنتَجة ومتحقَّقة** (v1.18.0) — 1,000 حالة موثقة ذاتياً، كلها مسنّدة إلى
نواة المعرفة الملتزمة (`data/knowledge/ryko.sqlite`)، والتحقق المستقل السبعي
ناجح بالكامل مع إيصال موقّع.

```
seed      : docs/benchmarks/ryko1000_seed.jsonl   (1,000 سطر، بناء مزدوج مطابق بايتياً)
verifier  : src/ryko_lm/eval/verify_ryko1000.py   (7 بوابات مستقلة)
builder   : src/ryko_lm/eval/build_ryko1000.py
receipt   : data/knowledge/ryko1000.receipt.json  (sha256 موقّع — تحقق دون اتصال)
coverage  : docs/results/ryko1000_coverage.md + ryko1000_verification.json
```

## المبدأ المعماري المثبّت

**RYKO ليس مجرد نموذج لغوي؛ بل منظومة معرفة واستدلال للتراث العربي والإسلامي**
تقوم على المصادر الموثقة، والاسترجاع، وذاكرة الخلاف، والتحقق والاقتباس.
لذلك لا يحل التدريب (SFT/DPO) محل قاعدة المعرفة ومحرك الأدلة — بل يُدرَّب على
بيانات مشتقة منها ومتحقَّقة منها.

## حقول الحالة (Schema `ryko1000/1`)

كل حالة تحمل الحقول العشرة المطلوبة في قرار اعتماد RYKO-1000:

1. **معرف فريد** — `ry10-<family>-<nnn>` مستقر عبر البناءات.
2. **السؤال والسياق** — `question` + `context`.
3. **الإجابة المتوقعة** — `expected_answer` (نص الخيار الصحيح، أو الاقتباس، أو
   الامتناع، أو المنشأ المنقّح).
4. **المصدر والمرجع** — `sources[]` ببروتوكول `ryko-cite/1`:
   `passage_id` / `book_id` / `title_ar` / `page_num` / `quote_sha256`.
5. **النص الداعم** — `supporting_text[]` (اقتباس حرفي داخل المقطع المسند).
6. **خطوات الاستدلال** — `reasoning_steps[]` (وصف مسار التحقق الفعلي لا
   محتوى مُخترع).
7. **الاعتراضات المحتملة** — `objections[]`.
8. **معيار قبول الإجابة** — `acceptance.criterion` (`mcq-answer` /
   `cite-verified` / `cite-not_found` / `abstain-must-refuse` /
   `abstain-must-answer`) + `min_citation_score: 1.0`.
9. **حالات فشل متعمدة** — `failure_probes[]` (تركيب، نسبة خاطئة، سؤال بلا
   سند) مع السلوك المطلوب (`not_found` / `reject` / `abstain`).
10. **نتيجة التحقق الآلي** — `verification` (فحص البناء الذاتي) + التقرير
    المستقل `ryko1000_verification.json` + الإيصال الموقّع.

متبقٍ متعمداً على مستوى المجموعة (وليس لكل حالة): **المراجعة البشرية** —
البناء تلقائي مُتحقَّق ذاتياً والتحقق مستقل، لكن قضايا الخلاف المذهبي والترجيح
تحتاج عيناً بشرية قبل أي دعوة أدائية (البذرة ليست مقيماً نهائياً — نفس أمانة
RYKO-Bench).

## البوابات السبع المستقلة (المولّد ليس الحكم)

| البوابة | العقد |
| --- | --- |
| الإحالات (`citations`) | كل مرساة تُحل في النواة؛ حكم ryko-cite/1 يطابق المتوقع؛ المصدر المسجّل يحوي الاقتباس حرفياً |
| الاقتباس (`quotes`) | كل نص داعم يرد حرفياً في مقطعه المسند |
| الإجابات (`answers`) | اتساق داخلي كامل (فهرس الخيار، قطبية الامتناع، نص الاقتباس) |
| التعارض (`contradictions`) | لا اقتباس مصطنع يمر كحقيقي؛ متعدد المصادر يغطي كتابين فعلاً |
| المذهبي (`madhhab`) | لا نسبة لمنطلق/كتاب دون سند مثبت (منشأ الدعوة، عنوان الكتاب، غياب العمل المسند إليه) |
| الامتناع (`abstention`) | الامتناع في عائلة اليقين فقط؛ رموز الغياب مُبرهَنة غيابها من كل مقطع |
| التكرار (`dedup`) | لا محتوى حالة شبه مطابق (Jaccard ≥ 0.90 على السؤال+السياق+الخيارات+الإجابة+الاقتباس+المصادر) |

**النتيجة على المجموعة الحقيقية: 7/7 ناجحة — 0 إخفاقات.**

## الانضباط الهندسي الموروث

* **الترحيل لا يعدّل**: بذرة RYKO-Bench الملتزمة (315) تُقرأ كأثر مجمد وتُجسَّر
  إلى المخطط الأغنى دون تغيير سطر فيها — كل النتائج التاريخية قابلة للمقارنة.
* **بناء حتمي مزدوج**: نفس المخزن + نفس البذرة ⇒ نفس الملف بايتياً (مُختبر).
* **RNG مستقل لكل عائلة** (إزاحات فريدة) — نمو المخزن لا يعيد ترقيم عائلة أخرى.
* **سقف حصة الكتاب** داخل كل عائلة (أقصى حصة ملاحظة: 16%) — لا كتاب يهيمن.
* **فشل بصوت عالٍ**: نقص البرك أو اصطدام الرموز أو كسر أي عقد يُفشل البناء، لا
  صمت.

## الانتقال إلى التدريب (بعد الاعتماد)

1. اختبار `ryko-small (52.2M)` وتحديد قدراته الفعلية على RYKO-1000.
2. تجهيز SFT بفصل بيانات التقييم (الخروج من البذرة إلى نص توجيهي مُقترن).
3. المرحلة 5 (SFT) وقياس التحسن مقابل خط الأساس (MCQ 26.42% / PalmX-IC 31.09%).
4. تفضيلات DPO موثقة مشتقة من `failure_probes` (الرفض مقابل الاختراع).
5. المرحلة 9 (DPO) ثم مقارنة مستقلة قبل/بعد.

## إعادة البناء والتحقق

```bash
python -m ryko_lm.eval.build_ryko1000 \
    --store data/knowledge/ryko.sqlite \
    --bench-seed docs/benchmarks/ryko_bench_seed.jsonl \
    --out docs/benchmarks/ryko1000_seed.jsonl
python -m ryko_lm.eval.verify_ryko1000 \
    --seed docs/benchmarks/ryko1000_seed.jsonl \
    --store data/knowledge/ryko.sqlite \
    --report docs/results/ryko1000_verification.json \
    --coverage-md docs/results/ryko1000_coverage.md \
    --receipt data/knowledge/ryko1000.receipt.json
python -m ryko_lm.provenance verify data/knowledge/ryko1000.receipt.json
```
